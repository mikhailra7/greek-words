# Импорт страниц учебника через Claude Code (путь 2)

Результат — `import_outbox/<имя>.zip`, который админ загружает на сайте:
**Словари → Импорт из учебника → Загрузить архив**. Дальше — обычный черновик.

Все команды — из папки `backend/`.

## Шаги

1. **Найди файл.** Пользователь кладёт PDF в `import_inbox/`. Если там DOC/DOCX или фото —
   попроси сохранить как PDF (конвертера нет). Если не ясно, какой файл, — спроси.

2. **Подготовь страницы:**
   ```bash
   .venv/bin/python scripts/import_package.py prepare ../import_inbox/<файл>.pdf
   ```
   Получишь `import_outbox/<имя>/pages/pN.jpg` — страницы с координатной сеткой.

3. **Возьми промпт с актуальным списком категорий:**
   ```bash
   .venv/bin/python -m app.cli import-prompt
   ```
   Прочитай каждую страницу (Read по `pages/pN.jpg`) и составь JSON строго по этим правилам —
   тот же промпт, что и для claude.ai. `page` — номер страницы в этом PDF, `category` —
   название из списка (или новое, если подходящей нет). Сохрани в
   `import_outbox/<имя>/import.json`.

4. **Собери архив и проверь картинки:**
   ```bash
   .venv/bin/python scripts/import_package.py build ../import_inbox/<файл>.pdf ../import_outbox/<имя>/import.json
   ```
   Открой `import_outbox/<имя>/sheet.jpg` и проверь **каждую** картинку:
   - рисунок целиком, не срезан;
   - **нет букв подписи** (иначе картинка подскажет ответ в тренажёрах);
   - нет соседних картинок.
   Поправь `bbox` в `import.json` и повтори шаг 4, пока всё не станет чисто.

5. **Отчитайся:** сколько слов, сколько с картинками, что было неоднозначно (сомнительные
   переводы, картинки с надписью, слова, которые пропустил и почему), путь к архиву.
   Не загружай архив на сайт сам — это делает админ.

## Правила, которые легко нарушить

- Форма слова — как в учебнике (мн. ч. остаётся мн. ч.), ед. ч. — в `note`.
- Артикль у каждого существительного, включая дни, месяцы, времена года.
- Слова из упражнений с пропусками не брать. Имена собственные — только если у них своя картинка.
- Картинка, на которой написано само слово, — `bbox: null` + `image_emoji`.
- Не трогать git.
