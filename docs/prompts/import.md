# Промпт импорта страниц учебника (v0.5)

Используется в двух местах: кнопка «Скопировать промпт» на сайте (путь 1, claude.ai)
и скилл импорта в Claude Code (путь 2). Проверен на `docs/samples/A1_Book_27_29.pdf`
(спайк 4.0, 2026-09-29).

---

Ты помогаешь составить словарь для русскоязычной группы, которая учит греческий (уровень A1).
Во вложении — PDF с несколькими страницами учебника (часто это скан). Страницы нумеруются
**по порядку в этом PDF, начиная с 1**, а не по номерам, напечатанным в учебнике.

На страницы нанесена **координатная сетка**: тонкие линии через каждые 0.05 ширины и высоты
страницы, по краям красные подписи 0.1 … 0.9. Сетка — только для измерения рамок картинок
(см. ниже), это не часть учебника.

## Что извлечь

Всю лексику, которую ученик должен выучить со страниц: подписи к картинкам, слова из списков,
слова из упражнений. Каждое слово — один раз, даже если оно встречается на нескольких страницах
(оставь первое вхождение с картинкой).

Не извлекай:
- слова из упражнений с пропусками (Δευτ_ρα, Φ_βρουάρ_ος) — их не восстанавливай;
- имена собственные (города, острова, страны, имена людей), **если у них нет своей картинки**.
  Имя собственное с отдельной иллюстрацией — извлекай, как обычное слово;
- служебный текст учебника: заголовки упражнений, инструкции («Βρίσκεις…», «Ακούς και λες»),
  номера треков CD, колонтитулы.

## Как записать слово

- `greek` — слово **строчными** буквами с ударением (τόνος), без артикля. Если в учебнике слово
  написано заглавными или с намеренными ошибками (упражнения «найди ошибки», «пиши строчными») —
  запиши правильное написание, а исходный вид укажи в `note`. Дни недели и месяцы — с заглавной
  (Δευτέρα, Αύγουστος), как принято в греческом.
- `article` — у **каждого** существительного определённый артикль: ο, η, το, οι, τα — в том числе
  у дней недели, месяцев и времён года (η Δευτέρα, ο Αύγουστος). Для остальных частей речи — null.
- Форма слова — **как напечатано в учебнике, не приводи к единственному числу**. Если в учебнике
  «μήλα», то `greek: "μήλα"`, `article: "τα"`, перевод «яблоки», а в `note` — «ед. ч. το μήλο».
- `transcription` — латиницей, вместе с артиклем, ударение — знаком над гласной:
  θ→th, χ→h, γ перед е/и-звуком→y (иначе g), γγ→ng, ου→u, αι→e, η/ι/υ/ει/οι→i,
  αυ/ευ→av/ev (перед глухими af/ef), ξ→ks, ψ→ps, τσ→ts, τζ→dz,
  μπ в начале слова→b (в середине mb), ντ в начале→d (в середине nd), γκ в начале→g.
  Двойные согласные пишутся одной буквой (κρεμμύδι → kremídi, Σάββατο → Sávato).
  Примеры: το νερό → «to neró», η γυναίκα → «i yinéka», το αγγούρι → «to angúri»,
  η τσάντα → «i tsánda», η άνοιξη → «i ániksi», το μαγιό → «to mayó» (γι перед гласной → y).
- `translations_ru` — 1–3 перевода на русский, самый частый первым. Для существительных —
  в том же числе, что и греческое слово.
- `part_of_speech` — одно из: noun, verb, adjective, adverb, pronoun, preposition, conjunction,
  numeral, phrase, other.
- `image_emoji` — одно подходящее эмодзи или null, если подходящего нет.
- `image_query` — 1–2 английских слова для поиска фото на стоке («lemon», «olive oil»);
  для абстрактных слов — null.
- `category` — одна смысловая категория слова. Бери название **точно** из списка ниже.
  Если ни одна не подходит — предложи новое короткое название по-русски (1–3 слова, в том же
  стиле, что и список): его проверит админ. Не создавай новую категорию ради одного-двух
  слов, если есть близкая по смыслу.
- `note` — короткое пояснение для проверяющего или null.

## Картинка к слову

Если на странице есть иллюстрация именно к этому слову, укажи:
- `page` — номер страницы в этом PDF (1..N);
- `bbox` — рамка иллюстрации `[x0, y0, x1, y1]` в долях ширины и высоты страницы (0..1),
  (0,0) — левый верхний угол. Меряй по сетке, с точностью до 0.005.

Рамка должна охватывать **весь рисунок и только его**:
- рисунок целиком, ничего не обрезано (весь лимон, вся бутылка, вся связка макарон);
- **ни одной буквы подписи**: нижний край рамки (`y1`) — выше верхнего края текста подписи.
  Если рисунок почти касается подписи, лучше срежь край рисунка, чем захватишь буквы —
  иначе картинка подскажет ответ в тренажёрах;
- без соседних картинок; рамку карточки можно не исключать. Если слово напечатано внутри самого рисунка (например, календарь с «Δευτέρα»),
такую картинку не бери: `bbox: null`, обязательно подбери `image_emoji`, а в `note` напиши
«на картинке написано слово».

Если картинки к слову нет — `page` укажи всё равно, `bbox: null`.

## Перед ответом — проверь себя

1. У каждого существительного есть артикль.
2. Слова во множественном числе остались во множественном.
3. Транскрипция — по правилам выше (ξ→ks, ντ в середине→nd, двойные согласные — одной буквой).
4. Для каждой рамки: рисунок внутри целиком, а подписи со словом внутри нет.
5. У каждого слова есть `category`, и если она из списка — название совпадает буква в букву.

## Формат ответа

Только JSON в одном блоке кода, без пояснений до и после:

```json
{
  "schema_version": 1,
  "title": "<короткое название: тема или номера страниц>",
  "words": [
    {
      "article": "το",
      "greek": "νερό",
      "transcription": "to neró",
      "translations_ru": ["вода"],
      "part_of_speech": "noun",
      "image_emoji": "💧",
      "image_query": "water",
      "category": "Еда и напитки",
      "page": 4,
      "bbox": [0.674, 0.633, 0.805, 0.704],
      "note": null
    }
  ]
}
```
