# Промпт для списка слов (v0.2)

Для слов без учебника: список в тексте, таблица, фото или скриншот списка. Ответ Claude
вставляется на сайте: **Словари → Как добавить словари → «Список слов» → поле «JSON от Claude»**
(или сохраняется в .json и загружается кнопкой «Загрузить JSON / архив»). Черновика и картинок
нет — словарь создаётся сразу, категории размечаются потом кнопкой «Без категории: N».
Правила формы слова и транскрипции — те же, что в `import.md`; меняешь там — поправь и здесь.

---

Ты помогаешь составить словарь для русскоязычной группы, которая учит греческий (уровень A1).
Ниже (или во вложении) — список греческих слов, возможно с переводами. Преврати его в JSON
по правилам ниже.

## Как записать слово

- `greek` — слово **строчными** буквами с ударением (τόνος), без артикля. Если в списке
  ошибка или нет ударения — запиши правильно, а исходный вид укажи в `note`. Дни недели и
  месяцы — с заглавной (Δευτέρα, Αύγουστος).
- `article` — у **каждого** существительного определённый артикль: ο, η, το, οι, τα. Если в
  списке артикля нет — определи его сам. Для остальных частей речи — null.
- Форма слова — как в списке (мн. ч. остаётся мн. ч., ед. ч. — в `note`).
- `transcription` — латиницей, вместе с артиклем, ударение — знаком над гласной:
  θ→th, χ→h, γ перед е/и-звуком→y (иначе g), γγ→ng, ου→u, αι→e, η/ι/υ/ει/οι→i,
  αυ/ευ→av/ev (перед глухими af/ef), ξ→ks, ψ→ps, τσ→ts, τζ→dz,
  μπ в начале слова→b (в середине mb), ντ в начале→d (в середине nd), γκ в начале→g.
  Двойные согласные — одной буквой (κρεμμύδι → kremídi).
  Примеры: το νερό → «to neró», η γυναίκα → «i yinéka», η τσάντα → «i tsánda».
- `translations_ru` — **от 1 до 5** переводов на русский, **не больше 5** (сайт не примет слово
  с шестью): самые частые, самый частый первым. Если вариантов больше — оставь 5
  самых употребительных, остальные можно перечислить в `note`.
  Если перевод в списке есть — возьми его. Для существительных — в том же числе, что и греческое слово.
- `part_of_speech` — одно из: noun, verb, adjective, adverb, pronoun, preposition, conjunction,
  numeral, phrase, other.
- `image_emoji` — одно подходящее эмодзи или null.
- `image_query` — 1–2 английских слова для поиска фото на стоке («lemon»); для абстрактных — null.
- `note` — короткое пояснение или null.

Каждое слово — один раз. Служебный текст (заголовки, номера, инструкции) не бери.

## Формат ответа

Только JSON в одном блоке кода, без пояснений до и после:

```json
{
  "schema_version": 1,
  "title": "<короткое название словаря по-русски>",
  "words": [
    {
      "article": "το",
      "greek": "νερό",
      "transcription": "to neró",
      "translations_ru": ["вода"],
      "part_of_speech": "noun",
      "image_emoji": "💧",
      "image_query": "water",
      "note": null
    }
  ]
}
```
