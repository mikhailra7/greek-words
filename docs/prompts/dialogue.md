# Промпт для диалога (v0.1)

Для раздела «Диалоги»: диалог из учебника (текст, фото, скриншот, PDF) превращается в JSON.
Ответ Claude вставляется на сайте: **Диалоги → «Вставить ответ Claude»** (или сохраняется в
.json и загружается кнопкой «Загрузить JSON» в «Диалогах» или «Словарях»). Правила
транскрипции — те же, что в `import.md` и `wordlist.md`; меняешь там — поправь и здесь.
Формат — SPEC, раздел «Диалоги», Д2.

---

Ты помогаешь русскоязычной группе (уровень A1) заучивать греческие диалоги. Ниже (или во
вложении) — диалог. Преврати его в JSON по правилам ниже.

## Роли

- `speakers` — 2 или 3 роли: имена из диалога, как в тексте (Μαρία, Νίκος). Если имён нет —
  «Α», «Β» (и «Γ»). Роли — в порядке первого появления.
- Если ролей в диалоге больше трёх — оставь три главных и напиши об этом одной строкой
  **после** блока JSON.

## Реплики

- `lines` — все реплики по порядку; `speaker` — номер роли в `speakers`, **с нуля** (0, 1, 2).
- `greek` — реплика целиком, как в тексте: с ударениями (τόνος), заглавными, знаками
  препинания (греческий вопросительный знак — «;»). Если в тексте опечатка или нет ударения —
  запиши правильно, а исходный вид укажи в `note`. Пропуски для упражнения («Με λένε ___»)
  заполни подходящим словом и укажи это в `note`. Ремарки и имя говорящего в `greek` не пиши.
- `transcription` — вся реплика латиницей, ударение — знаком над гласной, знаки препинания
  как в греческом, но «;» → «?»:
  θ→th, χ→h, γ перед е/и-звуком→y (иначе g), γγ→ng, ου→u, αι→e, η/ι/υ/ει/οι→i,
  αυ/ευ→av/ev (перед глухими af/ef), ξ→ks, ψ→ps, τσ→ts, τζ→dz,
  μπ в начале слова→b (в середине mb), ντ в начале→d (в середине nd), γκ в начале→g.
  Двойные согласные — одной буквой. Пример: «Γεια σου! Πώς σε λένε;» → «Ya su! Pos se léne?».
- `translation_ru` — естественный русский перевод всей реплики (не дословный).
- `note` — короткое пояснение (грамматика, вежливая форма, что исправлено) или null.
- Длина реплики — до 300 символов; длинную реплику одного говорящего раздели на две подряд.

## Формат ответа

Только JSON в одном блоке кода, без пояснений до и после (кроме случая с лишними ролями):

```json
{
  "schema_version": 1,
  "type": "dialogue",
  "title": "<короткое название по-русски: о чём диалог>",
  "speakers": ["Μαρία", "Νίκος"],
  "lines": [
    {
      "speaker": 0,
      "greek": "Γεια σου! Πώς σε λένε;",
      "transcription": "Ya su! Pos se léne?",
      "translation_ru": "Привет! Как тебя зовут?",
      "note": null
    }
  ]
}
```
