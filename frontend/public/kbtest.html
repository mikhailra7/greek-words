Тест: выбор клавиатуры удержанием пробела

В каждом поле: нажмите на поле, затем удерживайте пробел и выберите другую клавиатуру во всплывающем окне. Запомните номера полей, где окно выбора не закрылось само и клавиатура переключилась. Под каждым полем — журнал событий. Страница ничего не отправляет.

Режим клавиатуры:
обычный · resizes-content · overlays-content

1. Как в «Напиши» input + наши атрибуты

2. Простой input без атрибутов, как на большинстве сайтов

3. Поле поиска input type=search

4. Многострочное в одну строку textarea rows=1

5. Как у Google textarea + атрибуты поля поиска Google

6. Редактируемый блок contenteditable

7. Как в «Напиши» + возврат фокуса сразу если фокус ушёл без нажатия

8. Как в «Напиши» + возврат фокуса через 0,4 с если фокус ушёл без нажатия

9. Как в «Напиши» + касания мимо поля не забирают фокус как в подсказках поиска Google
